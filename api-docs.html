🔐 1. Authentication API (JWT)

Request Body (JSON):
{
  "email": "admin@northwind.co.th",
  "password": "••••••••"
}

{
  "status": true,
  "success": true,

    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "token_type": "Bearer",

    "user": {
      "id": 1,
      "name": "วชิรา ล.",

📦 2. Products API (tb_products CRUD)

GET /api/v1/products — ค้นหาและดึงรายการสินค้า
Headers:
Authorization: Bearer {token}
Accept: application/json
Query Parameters:
?search=ชาไทย
&category_id=1
&supplier_id=1
&min_price=10
&max_price=50
&page=1
&limit=25
Response 200 (Success):
{
  "status": true,
  "total": 79,
  "page": 1,
  "limit": 25,
  "totalPages": 4,
  "data": [
    {
      "i_ProductID": 1,
      "c_ProductName": "ชาไทย",
      "i_SupplierID": 1,
      "i_CategoryID": 1,
      "c_Unit": "10 กล่อง × 20 ถุง",
      "i_Price": 18.00,
      "c_CategoryName": "เครื่องดื่ม",
      "c_SupplierName": "Exotic Liquids",
      "status": "ใช้งานอยู่",
      "badge_class": "badge-green"
    }
  ]
}
POST /api/v1/products — เพิ่มสินค้าใหม่เข้าสู่ระบบ
Request Body (JSON):
{
  "c_ProductName": "กาแฟอาราบิก้าคั่วเข้ม",
  "i_CategoryID": 1,
  "i_SupplierID": 2,
  "c_Unit": "12 ถุง × 250 กรัม",
  "i_Price": 185.00
}
Response 201 (Created):
{
  "status": true,
  "code": 201,
  "message": "บันทึกสินค้าใหม่สำเร็จ รหัส #104",
  "data": {
    "i_ProductID": 104,
    "c_ProductName": "กาแฟอาราบิก้าคั่วเข้ม",
    "i_Price": 185.00
  }
}
PUT /api/v1/products/{id} — แก้ไขข้อมูลสินค้า
Request Body (JSON):
{
  "c_ProductName": "ชาเขียวมัทฉะแท้",
  "i_CategoryID": 1,
  "i_SupplierID": 1,
  "c_Unit": "20 ซอง",
  "i_Price": 150.00
}
Response 200 (Success):
{
  "status": true,
  "code": 200,
  "message": "อัปเดตข้อมูลสินค้ารหัส #1 เรียบร้อยแล้ว",
  "data": { "i_ProductID": 1 }
}
DELETE /api/v1/products/{id} — ลบข้อมูลสินค้า
Response 200 (Success):
{
  "status": true,
  "code": 200,
  "message": "ลบสินค้ารหัส #1 สำเร็จ"
}

📋 4. สรุป RESTful API Endpoints ทั้งหมด

Resource / Entity Method Endpoint URL คำอธิบาย
AuthenticationPOST/api/v1/auth/loginเข้าสู่ระบบและรับ JWT Token
AuthenticationGET/api/v1/auth/meตรวจสอบ Token ผู้ใช้ปัจจุบัน
DashboardGET/api/v1/dashboard/statsดึงสถิติภาพรวม 4 KPI และคำสั่งซื้อล่าสุด
ProductsGET/api/v1/productsค้นหาและกรองรายการสินค้า
ProductsPOST/api/v1/productsเพิ่มสินค้าใหม่ (Prepared SQL)
ProductsPUT/api/v1/products/{id}แก้ไขสินค้า
ProductsDELETE/api/v1/products/{id}ลบสินค้า
CategoriesGET/api/v1/categoriesดึง 9 หมวดหมู่พร้อมจำนวนสินค้า
CategoriesPOST/api/v1/categoriesสร้างหมวดหมู่ใหม่
OrdersGET/api/v1/ordersดึงรายการคำสั่งซื้อและกรองสถานะ
OrdersGET/api/v1/orders/{id}รายละเอียดคำสั่งซื้อ + Line Items
CustomersGET/api/v1/customersทะเบียนลูกค้า 91 รายการ
SuppliersGET/api/v1/suppliersทะเบียนผู้จัดจำหน่าย 29 ราย
EmployeesGET/api/v1/employeesรายชื่อพนักงาน 10 คน
ShippersGET/api/v1/shippersบริษัทขนส่ง 3 บริษัท
ReportsGET/api/v1/reports/summaryสรุปรายงานยอดขายและลูกค้าชั้นนำ
ReportsGET/api/v1/reports/exportดาวน์โหลดรายงานในรูปแบบ CSV
HealthGET/api/v1/healthตรวจสอบสถานะการเชื่อมต่อ MySQL
